# App chấm công Hải Anh

Web app React + Tailwind + Supabase.

## Chức năng
- Quản lý nhân viên
- Quản lý công trình
- Chấm công theo ngày
- Tăng ca 150%, tăng ca Chủ nhật 200%
- Phụ cấp Hà Nội/tỉnh
- Tạm ứng
- TNCN 10%
- BHXH
- Xuất Excel bảng lương

## Deploy
1. Upload toàn bộ source lên GitHub.
2. Import GitHub repo vào Vercel.
3. Thêm Environment Variables:
   - VITE_SUPABASE_URL
   - VITE_SUPABASE_ANON_KEY
4. Redeploy.
